### 今日剩余安全注意事项

当前服务器系统内部已经完成可以安全执行的收紧动作，但 SSH 仍需要后续确认后处理：

```text
22 端口仍对公网可达
SSH 仍允许 root 密码登录
服务器仍有海外 IP 的 SSH 失败登录尝试
```

下一步需要客户或开发方在阿里云控制台收紧安全组：

```text
80、443 保持公网开放
22 只允许开发者固定 IP
8888、3306、21、3000 不开放
```

关闭 SSH 密码登录前，需要先确认客户和开发方都已经能用 SSH 公钥登录，避免客户无法进入服务器。

JS 侧使用 `.vanglam-hero-image` 的布局位置和尺寸计算坐标，避免 3D transform 过程中 `getBoundingClientRect()` 变化造成反馈误差。
