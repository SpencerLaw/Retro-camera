# Tesla 车型感知自定义车衣工作台实施计划

## 任务 1：编辑器基础设施

- 安装 `konva` 与 `react-konva`。
- 新增车型工作台类型、图片读取和 mask 边界工具。
- 建立可撤销的图层状态与车型切换重适配逻辑。
- 验证 TypeScript/Vite 构建。

## 任务 2：车型感知画布

- 实现固定 1024×1024 Konva Stage。
- 加载当前车型官方模板并生成车身 mask。
- 实现图片上传、车型感知初始适配、完整显示、铺满车身和居中。
- 实现拖动、Transformer 四角缩放/旋转、滚轮缩放、触控缩放、中心吸附和键盘微调。
- 输出不含辅助层的 1024×1024 PNG 纹理。

## 任务 3：工作台 UI

- 实现桌面图层栏、中央大画布和右侧属性面板。
- 实现移动端画布优先和底部工具抽屉。
- 加入文件校验、清晰度警告、本地处理说明和空状态上传区。
- 保持 Tesla 工程化展厅视觉系统和 CJK 可读性。

## 任务 4：集成现有模块

- 用新工作台替换 `TslSkinApp` 旧自定义上传卡片和原生 Canvas 区域。
- 保留图库、车型选择、3D Dialog、下载和主题切换。
- 让 2D 编辑纹理、3D 预览和下载使用同一输出。

## 任务 5：验证与交付

- 运行生产构建。
- 在桌面 1280、平板 768、手机 375 进行功能与视觉检查。
- 验证上传、拖动、缩放、旋转、适配模式、车型切换、3D Dialog 和下载。
- 根据视觉 QA 修复问题，更新 `DESIGN.md`。
