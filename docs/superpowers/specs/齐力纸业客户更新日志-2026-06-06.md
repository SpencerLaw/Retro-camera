## 九、当前仍需客户或项目方确认的事项

当前服务器内部已经完成本阶段可以安全执行的处理，但仍有几个后续事项需要确认。

### 1. 阿里云安全组需要继续收紧

服务器内部服务已经做了收紧，但云厂商安全组需要在阿里云控制台继续处理。

建议规则：

```text
80    允许公网访问
443   允许公网访问
22    只允许开发者固定 IP 访问
8888  不开放
3306  不开放
21    不开放
3000  不开放
```

说明：

服务器目前仍能看到 SSH 被海外 IP 扫描的记录。最直接的处理方式，是在阿里云安全组里把 SSH 22 端口限制为开发者固定 IP 访问。

### 2. SSH 密码登录需要确认后再关闭

当前 SSH 仍允许 root 密码登录。

建议后续处理：

1. 确认客户、开发方和维护人员都已经配置好 SSH 公钥。
2. 确认至少保留一个已登录 SSH 窗口。
3. 再关闭 SSH 密码登录。
4. 再调整 root 登录方式。

没有直接关闭的原因：

```text
如果客户还没有配置 SSH 公钥，直接关闭密码登录可能导致客户无法登录服务器。
```

### 3. 正式后台开发前建议重新规划服务端

当前上线的是新官网前端，不是完整后台。

后续后台开发建议重新规划：

1. 后台管理系统。
2. 数据库结构。
3. 图片、视频、资料文件上传。
4. 官网内容接口。
5. 小程序共用 API。
6. 管理员账号和权限。
7. 操作日志。
8. 备份和维护流程。

当前旧网站后台不建议作为长期后台继续使用。
